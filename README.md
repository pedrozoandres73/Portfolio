# Portfolio · Andrés Pedrozo

Sitio estático (HTML + CSS + JS). Sin dependencias ni build, salvo las tipografías de Google Fonts.

## Completar
- `script.js` → objeto `CONFIG`: correo, LinkedIn y GitHub.
- `index.html` → sección Proyectos: reemplazá las tarjetas de demostración por trabajos reales (imágenes en `assets/`).

## Publicar
- **GitHub Pages:** subí la carpeta a un repositorio → Settings → Pages → rama `main`, carpeta `/ (root)`.
- **Vercel:** importá el repositorio; no requiere configuración.
